# AgeVolt Developer Tools Marketplace

Marketplace pre developerov, technickych adminov a technicke QA workflowy.

Ma sluzit ludom, ktori pracuju s kodom, repozitarmi, pull requestami, CI, frontend pravidlami, DataGridom, nastaveniami, technickou dokumentaciou alebo vyvojarskymi helpermi.

Tento marketplace nema byt instalovany beznym zamestnancom ani vyrobe, pokial ho realne nepotrebuju. Je urceny pre technicke role.

Aktualny stav: pripravene ako prazdny marketplace, bez pluginov.
